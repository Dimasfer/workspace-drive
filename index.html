Workspace Drive

Workspace Drive is a personal file synchronization setup maintained by Dimasfer. It uses rclone and the Google Drive API to copy selected workspace files from the owner's computer to the owner's private Google Drive and to provide on-demand file access on another computer controlled by the same owner.

A separate exchange folder allows the owner to transfer working files between these computers. The setup is for the owner's personal use; it is not a public sign-in service.

This website contains documentation only. It does not contain workspace files, access tokens or an application login.
