Workspace Drive privacy policy

Last updated: November 7, 2026.

Workspace Drive is a personal setup maintained by Dimasfer for the owner's own Google account and computers.

Access and purpose

With the owner's permission, rclone uses Google Drive authorization to list file and folder metadata, read file contents and create or update the selected private backup and exchange files. The Google Drive permission can allow broader file management; the configured workspace copy does not delete source files, and the general viewing mount is read-only. The separate exchange mount permits file changes requested by the owner.

Storage and sharing

Selected files are stored in the owner's Google Drive and on the owner's authorized computers. Files opened through the remote mount may be cached temporarily on the owner's other computer. Authorization tokens and client configuration are stored in restricted local configuration files. This documentation website stores no workspace files or authorization credentials.

Google user data is used only to provide the requested file synchronization and access. It is not sold, used for advertising, or used to train generalized artificial intelligence models. This setup does not send file contents to an analytics service. Any separate sharing or AI connector selected by the owner is outside this synchronization setup and subject to the owner's instructions and that service's terms.

Retention and control

The owner controls the stored files, prior versions and caches. Disabling the setup stops future transfers; existing copies remain until the owner removes them. The owner can revoke access in their Google Account's third-party connections settings and remove local authorization files.

Workspace Drive's use of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

This website

The documentation is hosted by GitHub Pages, which may process request information under GitHub's privacy statement. These pages contain no analytics scripts or application cookies.

For questions, contact the maintainer; do not post private files, passwords or tokens in public issues.
